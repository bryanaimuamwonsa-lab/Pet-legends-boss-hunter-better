# Pet Legends 3D: Rift Champions

Open `index.html` in Chrome while connected to the internet. Three.js loads from jsDelivr.

Controls:
- Laptop: WASD or arrow keys to move around the overworld.
- Phone: on-screen direction pad.
- Travel north to the distant glowing gate, tap DUNGEONS, and enter an unlocked dungeon.
- Manage Team lets you choose up to five original companion creatures.
- In a boss battle use ATTACK, SPARK, BURST, HEAL, and ULT.

This is an original single-player prototype inspired by team arena battlers, not an exact Pokémon UNITE copy. It uses procedural 3D models, not professionally hand-made assets, and can be expanded further.
